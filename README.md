# 정시 방송

정해진 요일·시각에 PC 스피커로 안내 방송을 내보내는 Windows 앱입니다.
방송 시각이 되면 브라우저 영상이나 음악 같은 다른 소리를 잠시 멈추고, 음성 안내(TTS)와 음악을 순서대로 재생한 뒤 원래 상태로 되돌립니다.

## 기능

- **시간표**: 회차(이름·시각·요일·방송 구성)를 요일별 표로 보고 관리합니다.
- **방송 구성**: 차임 → 음성 ×2 → 음악처럼 단계를 쌓습니다. 단계마다 반복 횟수(1~20)와 반복 사이 간격을 정합니다.
- **예외 일정**
  - 쉬는 날: 하루 또는 기간(방학·휴가)
  - 특정 날짜의 한 회차만 쉬기, 시각·구성 바꾸기
  - 우선순위: 회차 변경 > 쉬는 날 > 주간 일정
- **방송 제어**: 이번(다음) 방송 끄기와 되돌리기, 지금 방송, 방송 중 "다음 단계로"·"방송 끄기"
- **다른 소리 처리**: 재생 중인 미디어 일시정지 → 다른 앱 음소거 → 방송 음량 적용 → 끝나면 역순 복원. 앱이 방송 도중 꺼져도 다음 실행 때 복원합니다.
- **기록 없음**: 방송 기록은 남기지 않습니다. 방송이 실패하면 화면 위쪽에 알림만 보여 줍니다.
- **트레이 상주·자동 실행**: 창을 닫으면 트레이로 갑니다(설정에서 변경).
- **업데이트**: 새 GitHub 릴리즈가 있으면 위쪽에 업데이트 버튼이 나타납니다. 버튼을 누르면 받아서 다시 시작합니다.
- 밝은·어두운 테마

## 설치

1. [Releases](https://github.com/yujia-cha/broadcast/releases)에서 `JeongsiBroadcast.exe`를 받습니다.
2. 쓰기 권한이 있는 폴더에 둡니다. 권장 위치는 `%LOCALAPPDATA%\Programs\JeongsiBroadcast\`입니다. `Program Files`에 두면 자동 업데이트가 파일을 바꿀 수 없습니다.
3. 실행합니다. 서명하지 않은 exe라 처음에 SmartScreen 경고가 뜰 수 있습니다. **추가 정보 › 실행**을 누르세요.
4. 처음 실행하면 Windows 로그인 시 자동 실행이 켜집니다(설정에서 끌 수 있음).

**한국어 음성**: Windows 설정 › 시간 및 언어 › 음성(또는 언어 및 지역 › 한국어 › 언어 옵션)에서 한국어 음성을 추가하세요. 음성이 없으면 앱 위쪽에 안내가 표시됩니다.

**알아둘 점**

- PC가 꺼져 있거나 절전 중이면 방송하지 않습니다. 예정 시각에서 60초가 지나면 그 방송은 건너뜁니다. 방송용 PC는 절전을 꺼 두세요.
- "지금 방송"은 예약과 별개로 바로 내보냅니다. 예약된 방송도 그대로 나가므로, 원하지 않으면 "이번 방송 끄기"를 함께 누르세요.

## 데이터 위치

`%APPDATA%\JeongsiBroadcast\`

| 파일 | 내용 |
|---|---|
| `config.json` | 방송 구성, 시간표, 예외, 설정 |
| `media\` | 올린 소리 파일 |
| `logs\app.log` | 문제 확인용 로그 |

설정 화면의 "설정 내보내기·가져오기"로 다른 PC에 옮길 수 있습니다. 소리 파일은 `media` 폴더를 함께 복사하세요.

## 개발

```bash
pip install -e ".[dev]"          # Windows에서 실제 오디오까지: ".[dev,windows]"
python -m jeongsi --dev          # 가짜 오디오로 서버만 실행 → http://127.0.0.1:48650
python -m pytest -q
```

`--dev`는 실제 소리를 내지 않고 재생 시간만큼 기다립니다. Windows가 아닌 환경에서도 화면과 일정 로직을 확인할 수 있습니다.

### 구조

```
src/jeongsi/
  models.py      데이터 모델과 검증
  schedule.py    날짜별 방송 계산(우선순위 규칙)
  scheduler.py   예정 시각에 방송을 넣는 시계 루프
  runner.py      방송 실행·소리 상태 복원
  audio/         오디오 인터페이스(base), Windows 구현, 가짜 구현
  app.py         로컬 웹 API
  static/        화면(HTML·CSS·JS, Pretendard 글꼴)
  desktop.py     앱 창(WebView2)·트레이·자동 실행
  updater.py     GitHub 릴리즈 업데이트
```

### 릴리즈

```bash
git tag v0.1.0
git push origin v0.1.0
```

`Release` 워크플로가 다음 순서로 진행하고, 하나라도 실패하면 릴리즈를 만들지 않습니다.

1. 테스트(Linux·Windows, 화면 E2E)
2. Windows에서 exe 빌드 후 배포 스모크 테스트(`tools/smoke_exe.py`): 개발·실제 모드 실행, Windows 오디오로 방송, 자동 실행 등록·해제, 로컬 가짜 릴리즈로 업데이트 교체·재시작
3. `JeongsiBroadcast.exe`와 `JeongsiBroadcast.exe.sha256`을 릴리즈에 올림

브랜치에 푸시할 때마다 CI가 1·2단계를 돌리고, 빌드한 exe를 Actions 아티팩트(`JeongsiBroadcast-windows`)로 14일간 보관합니다. 릴리즈 전에 받아서 직접 시험할 수 있습니다. 설치된 앱은 이 두 파일로 업데이트합니다. 태그는 `v숫자.숫자.숫자` 형식이어야 합니다.

**되돌리기**

- 문제가 있는 릴리즈는 GitHub에서 삭제하거나 사전 릴리즈(pre-release)로 바꾸세요. 앱은 정식 릴리즈만 확인합니다.
- 이미 업데이트한 PC는 같은 폴더에 남은 `JeongsiBroadcast.old.exe`의 이름을 `JeongsiBroadcast.exe`로 바꾸면 이전 버전으로 돌아갑니다. 새 버전이 정상 시작하면 이 파일은 지워지므로, 그 뒤에는 릴리즈 페이지에서 이전 버전을 받으세요.

## Windows 수동 점검표

자동 테스트는 가짜 오디오로 돌기 때문에, 실제 소리 제어는 Windows에서 직접 확인해야 합니다.

- [ ] YouTube(Chrome·Edge) 재생 중 "지금 방송" → 영상이 일시정지되고, 끝나면 다시 재생된다
- [ ] 일시정지를 지원하지 않는 앱(게임, 알림음) → 방송 동안 음소거되고 끝나면 풀린다
- [ ] 방송 전에 음소거해 둔 앱 → 방송 뒤에도 음소거 그대로다
- [ ] 시스템 음량 30%·음소거 상태 → 방송은 설정 음량(70%)으로 들리고, 끝나면 30%·음소거로 돌아간다
- [ ] 방송 중 "다음 단계로" → 다음 단계로 넘어간다. "방송 끄기" → 바로 멈추고 소리가 복원된다
- [ ] 방송 중 작업 관리자로 앱 종료 → 다시 실행하면 음소거·음량이 복원된다
- [ ] 한국어 음성으로 TTS가 나온다. 단계별 음성·속도 변경이 반영된다
- [ ] mp3·wav·flac·ogg 파일이 재생된다
- [ ] 창 닫기 → 트레이로 간다. 트레이 메뉴 열기·방송 끄기·자동 방송·종료가 동작한다
- [ ] 재부팅 후 로그인 → 트레이로 자동 시작된다(창은 설정에 따라)
- [ ] exe를 한 번 더 실행 → 새로 뜨지 않고 기존 창이 열린다
- [ ] 예약 시각에 방송된다. 시각 변경·쉬기·쉬는 날이 시간표대로 적용된다
- [ ] 새 릴리즈가 있으면 업데이트 버튼이 보이고, 누르면 새 버전으로 다시 시작된다
